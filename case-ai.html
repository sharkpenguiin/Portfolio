Case 02 · AI 시스템차별화 핵심

반복 업무를
시스템으로 바꾸다

녹취·회의가 검증된 산출물이 되기까지를 하나의 파이프라인으로 설계했습니다.
스킬 10종·SSOT 봇·STT 사전·5대 기준으로 사람의 판단 지점을 남겼습니다.

5검증 기준

문제

Problem

같은 일을 매번 또 손으로

회의록 정리·명세 작성·검수가 매 프로젝트마다 반복되며 사람에 따라 품질이 흔들렸습니다.

답은 늘 여기저기 흩어져 있고

“이거 어떻게 정해졌죠?” 질문의 답이 슬랙·문서·기억에 분산돼 있었습니다.

AI 결과는 그대로 믿기엔 불안

AI 초안은 빠르지만 근거·정합성 검증 없이는 산출물에 쓸 수 없었습니다.

판단

Judgment

AI에게 맡길 영역과 사람이 판단할 경계를 먼저 설계했습니다.

01

반복 작업을 스킬 10종으로

회의록 정리, 기능명세 작성, QA 체크리스트, 리스크 점검 등을 커스텀 AI 스킬로 규격화해 1차 구조화를 자동화했습니다. 제작한 스킬은 PM 챕터에 공유했고, 현재 대표를 포함한 PM 4명 전원이 실사용 중입니다.

개인 도구가 아니라 팀의 업무 방식이 됐습니다.

02

단일 진실 소스(SSOT) + Q&A 봇

결정·문서를 SSOT로 모으고, 슬랙 Q&A 봇이 그 근거를 인용해 답하도록 구성해 “어떻게 정해졌는지”를 즉시 확인합니다.

03

5대 검증 기준으로 사람이 통제

근거 검증·중복 제거·자동/수동 경계·실제 업무 동선·데이터 정합. 이 다섯 가지를 통과한 산출물만 확정합니다.

STT 커스텀 사전으로 도메인 용어 인식률까지 관리합니다.

산출물

Output

직접 설계·운영한 AI 스킬 세트 (일부) · SSOT Q&A 봇 (실제 산출물 기반 재현본 · 고객사·사내 정보 비식별화).

검수 원칙

· 꼼꼼하면 꼼꼼할수록 좋다. 사소한 것도 놓치지 않는다.

· 이슈 발견 시 즉시 PM에게 공유하고 의견을 말한다. 수정은 반드시 PM 확인 후 진행한다.

· 검수 후 수정이 필요하면 직접 편집이 아니라 JSON 패치를 생성한다 — PM이 Apps Script로 적용하는 흐름.

AI에게도 “수정은 PM 확인 후”를 규칙으로 박아둔 것 — 자동화 안에서도 최종 판단은 사람이 갖습니다.

5대 검증 기준

Verify

AI 산출물은 이 5개 기준을 사람이 통과시킨 것만 확정합니다.

01

근거 검증

모든 문장이 소스에 근거하는지 확인. 출처 없는 내용은 산출물에서 제외.

02

중복 제거

동일·유사 요구가 여러 곳에 흩어지지 않도록 병합·정리.

03

자동/수동 경계

AI가 처리할 부분과 사람이 판단할 부분의 경계가 명확한지 점검.

04

실제 업무 동선

현업이 실제로 일하는 순서·맥락과 산출물이 맞는지 확인.

05

데이터 정합

필드·값·상태가 다른 문서·화면과 논리적으로 어긋나지 않는지 검증.

SSOT 슬랙 Q&A 봇 Hermes

Hermes

“이거 어떻게 정해졌죠?”에 근거를 인용해 답하는 봇. 오픈소스 에이전트 Hermes를 붙여 SSOT 기반으로 구성했고, 소스 큐레이션 → 검증 루프 3스텝으로 운영합니다.

01 · Curate

소스 큐레이션

결정로그·명세·회의록을 SSOT로 모으고 인덱싱.

02 · Answer

근거 인용 응답

Hermes가 질문에 SSOT 출처를 인용해 답변.

03 · Loop

검증 루프

틀린 답은 소스로 되짚어 SSOT를 교정하는 피드백 루프.

3단계 검수

Review

정방향

소스 → 산출물: 요구가 빠짐없이 반영됐는지.

역방향

산출물 → 소스: 근거 없는 내용이 섞이지 않았는지.

표본

무작위 표본을 심층 대조해 품질 신뢰도 확인.

40%↓본인 업무 시간 (실측)
4명PM 챕터 전원 실사용
Principle

기준은 실수의 기록이다

5대 기준은 이론이 아니라, 겪은 실수를 규칙으로 굳힌 것입니다. 한번은 AI가 근거 없이 만들어낸 항목을 '자동 승인'으로 흘려보낼 뻔했고, 그 사건이 근거 검증과 자동/수동 경계 기준으로 남았습니다. 기준이 늘어난다는 건, 같은 실수를 다시 하지 않는다는 뜻입니다.

결과

Result
40%↓

반복 기획 업무 시간 (본인 업무 시간 실측 기준)

일관

사람이 바뀌어도 산출물 품질·서식 일관 유지

추적
